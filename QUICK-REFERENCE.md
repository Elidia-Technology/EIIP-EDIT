## ⚡ Quick Workflows

### Social Media Image
```
1. Upload → 2. Crop [C] → 3. Resize [R] (1080×1080)
4. Adjust [A] → 5. Filter [E] → 6. Optimize [O] → Save
```

### Add Watermark
```
1. Upload → 2. Resize [R] → 3. Watermark [W]
4. Compress [K] → Save
```

### Photo Enhancement
```
1. Upload → 2. Crop [C] → 3. Adjust [A] (brightness/contrast)
4. Sharpen (Filters [E]) → Save
```

## 🎯 Pro Tips

```
✓  Work with high-resolution source images
✓  Apply adjustments BEFORE compression
✓  Use PNG for transparency, JPEG for photos
✓  Crop before resizing for better quality
✓  Test different positions for text overlay
✓  Use Reset button if you make a mistake
✓  Keyboard shortcuts speed up workflow
✓  Check image dimensions in top-right corner
```
